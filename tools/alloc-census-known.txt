# ---------------------------------------------------------------- bsd-expunge

# EMPTY, AND IT MUST STAY EMPTY.  This is the segment being unloaded: nothing

# ------------------------------------------------------------- bsd-stack-down
#
# The LAST CLOSE, when the stack comes down and the library is still loaded.
# These four are not leaks: they are what the library is entitled to hold
# between one program and the next, and bsd_lib_expunge() frees every one of
# them, which is why the scope above is empty.  They are listed so that GROWTH
# is a failure -- this is the scope every existing on-Amiga harness reaches
# without having to provoke an expunge, so it is the cheap gate.
